## Project discovery
- Source modules use `.js` import suffixes under NodeNext; tests import their TypeScript sources through the same suffix.
- `main()` passes the parsed adapter to every session; the test-only executable override is `io.launcher`.
- Shared agent fixture tests use `FAKE_AGENT_STATE_DIR`; fake Codex also accepts the older `FAKE_CODEX_STATE_DIR` for existing tests.
